# 老挝语图鉴

面向中文读者的老挝语词汇与短语学习网站。包含 3,500 个按书面语料词频筛选、
合并已知同词异写的词头，以及 106 条场景短语。主词条采用随站内嵌的
Noto Sans Lao Looped 常规教科书式字形。

## 打开与使用

- 在线访问 GitHub Pages 主页，或下载本仓库并双击 index.html。纯静态，无须安装依赖。
- 首页提供基础入门词序；词库按收录词条的语料频率排序，可搜索老挝文、中文、英文及转写。
- 在词卡中揭示释义，再选择复习间隔。练习页可做释义选择题或老挝文拼写题。
- 词本可收藏词汇和短语、记笔记、复习错题，或粘贴老挝语段落查词。
- 设置中可导出和合并 JSON 学习记录。进度存储在当前浏览器，同一文件和不同网址可能使用不同存储空间。
- 设备有老挝语语音时可以朗读。词典转写、万象音 IPA 和短语无声调读音提示分别标注。
- 频率来自 Unicode Unilex。排除无法辨认的片段，并合并已知异写，避免把同一个词计两次。
  中文学习义为整理译写，尚待母语教师逐项校订。详见页面底部的“词库来源与读音说明”及 CREDITS.txt。

## 发布与维护

在此组织网站仓库的 Settings → Pages 选择 Deploy from a branch、main、/(root)。
index.html、sw.js 和 CREDITS.txt 置于仓库根目录。首页内含词库、交互程序、样式、字体及许可，
可单独保存离线使用。数据位于 index.html 中 id 为 atlas-data 的 JSON 节点。更新页面后同步
修改 sw.js 里的缓存版本，以便离线用户获得新版。

数据、字体与第三方许可见 CREDITS.txt。
